# Fibonacci en Tafelkaart (PHP)

Een PHP-script met twee functies voor schoolopdrachten: een Fibonacci-reeks generator en een tafelkaart generator.

## Functies van het script
- **Fibonacci:** Genereert een Fibonacci-reeks tot een opgegeven aantal stappen $n$ en geeft dit weer als een getekende reeks (bijv. `1, 2, 3, 5, 8, ...`).
- **Tafelkaart:** Maakt gebruik van geneste `for`-loops (een buitenste loop voor de rijen en een binnenste loop voor de kolommen) om een vermenigvuldigingstabel van 1 tot $n$ te genereren.

## Hoe te gebruiken

1. Zorg dat PHP op je computer is geïnstalleerd.
2. Open de terminal in de map waar het script staat.
3. Voer het script uit met het volgende commando:
   ```bash
   php script.php
